API 文档

灌溉管理系统对外 API 说明 · 所有示例中的 {{ api_base }} 为本服务地址。

快速开始：① 在 个人资料 页查看你的 API 令牌，或调 POST /api/auth/login 换取； ② 每个请求加请求头 Authorization: Token <你的令牌>； ③ 按下方示例调用。报表导出等数据 API 仅限管理员/经理令牌。
{# ── 认证 ── #}

🔐 认证

系统支持两种认证方式：

方式一：Token（外部平台 / AI / 脚本）

在请求头携带 Authorization: Token <uuid>。令牌每账号一个，在「个人资料」页查看或重新生成。

curl -H "Authorization: Token cab094fa-xxxx-xxxx" \
  "{{ api_base }}/api/today-weather/"

方式二：登录 Session（浏览器内）

网页内 AJAX 自动带 cookie，无需额外配置。本页所述的 token 鉴权 API 在浏览器内同样可用（已登录即可）。

权限说明：报表导出 + 只读数据 API 的 token 路径仅限管理员/经理令牌（ManagerProfile）。现场工人/部门用户的令牌调用会返回 403。移动 App 走独立的 REST 资源（见下文），不受此限制。
{# ── 登录换令牌 ── #}

🔑 登录与令牌

POST/api/auth/login公开

用用户名密码换取 API 令牌。返回 JSON 含 token 及用户角色信息。

curl -X POST "{{ api_base }}/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "你的密码"}'

响应示例：{"token": "cab094fa-...", "role": "manager", "full_name": "..."}

{# ── 报表导出 ── #}

📊 报表导出（Excel）

按报表类型 + 日期范围生成 .xlsx 并以附件返回。仅限管理员/经理令牌。

GET/api/report-exports/<report_type>/仅管理员/经理

支持的报表类型：

work_reports 维修工单 irrigation 灌溉运行 inventory_txn 库存流水 zones 区域目录 inventory_catalog 库存目录 purchase_orders 采购订单 projects 项目管理
参数必填说明
report_type是（路径）上表 7 种之一
start否起始日期 YYYY-MM-DD。留空默认最近 30 天（仅对日期型报表生效）
end否结束日期 YYYY-MM-DD

注：zones / inventory_catalog / purchase_orders / projects 为目录类报表，忽略日期参数，导出全量。

curl -H "Authorization: Token <管理员令牌>" \
  "{{ api_base }}/api/report-exports/work_reports/?start=2026-07-01&end=2026-07-31" \
  -o 维修工单.xlsx
{# ── 只读数据 API ── #}

📡 只读数据 API（管理员/经理令牌）

下列 API 均需 Authorization: Token <管理员/经理令牌>，返回 JSON。

GET/api/work-reports/subsections/仅管理员/经理

按工作类别取一级子项（给筛选联动下拉用，也可枚举工单类别）。

参数必填说明
section是工作类别 code：routine_maint/irrigation_project/repair_emergency 等
curl -H "Authorization: Token <令牌>" \
  "{{ api_base }}/api/work-reports/subsections/?section=routine_maint"
GET/api/maxicom-dashboard仅管理员/经理

系统总览 KPI（片区数 / 控制器 / 站点 / 气象站 / 事件数）。

POST/api/custom-report仅管理员/经理

自定义图表数据聚合。请求体 JSON：{"charts": [{"id":"...", "dataSource":"...", "metric":"...", "dateFrom":"...", "dateTo":"..."}]}

GET/api/today-weather/仅管理员/经理

当日天气摘要（温度、天气、降水）。

GET/api/zone-geo/仅管理员/经理

区域地理边界数据（GeoJSON 形式）。

GET/api/zones-payload/仅管理员/经理

区域列表（编号、名称、片区、面积、灌水器类型）。

GET/api/modal/workorder-data/ 等 3 个

详情弹窗数据：workorder-data（工单）/ water-request-data（需求）/ inventory-data（库存）。传 ?id= 指定记录。

GET/api/planned-maintenance/pending/仅管理员/经理

待修 PM 工单列表（计划性维修积压）。

GET/api/equipment-catalog/autocomplete仅管理员/经理

设备目录联想。参数 ?q= 关键字。

{# ── REST 资源 ── #}

🗂️ REST 资源（DRF · 移动端 / 任意令牌）

下列资源走 DRF Router，支持标准 CRUD。所有角色令牌（管理员/经理/工人/部门用户）均可读；写操作受角色权限约束。每个资源提供 list / retrieve / create / update / destroy。

资源URL说明
区域/api/zones/灌溉区域（含自定义 /zone-detail/ 动作）
工人/api/workers/现场作业人员
工单/api/work-reports/维修工单（含 /upload-photos/、/remove-photo/ 动作）
浇水需求/api/water-requests/用水申请
设备目录/api/equipment-catalog/设备物料台账
区域设备/api/zone-equipment/区域-设备关联
管线/api/pipelines/灌溉管线
片区/api/patches/地块片区
区域/位置/api/regions/ /api/locations/地理层级

用法示例

# 列表（分页）
curl -H "Authorization: Token <令牌>" "{{ api_base }}/api/zones/?page=1"

# 单条详情
curl -H "Authorization: Token <令牌>" "{{ api_base }}/api/work-reports/42/"

# 新建工单
curl -X POST -H "Authorization: Token <令牌>" \
  -H "Content-Type: application/json" \
  -d '{"date":"2026-08-02", "remark":"示例"}' \
  "{{ api_base }}/api/work-reports/"
{# ── 公开 API ── #}

🌦️ 公开 API（无需认证）

GET/api/weather公开

天气数据（当前小时及前后区间）。参数 ?lat= &lon= 可选。

{# ── 错误码 ── #}

⚠️ 响应与错误码

状态码含义
200成功（GET / 成功的写操作）
201创建成功（POST）
400参数错误（日期格式不对、未知 report_type 等），JSON 含 error 字段
401未认证（缺令牌或令牌无效）
403无权限（如非管理员令牌调用管理员 API）
404资源不存在
安全提示：API 令牌等同于账号密码，请妥善保管，不要提交到代码仓库或日志中。如怀疑泄露，前往 个人资料 页「重新生成令牌」即可让旧令牌立即失效。
