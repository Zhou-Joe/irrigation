DXF 管线导入

上传 CAD 管网图 → 识别图层（管径）/ 阀门块 / 文字标注 → 地图预览确认 → 创建水管与阀门。坐标按站点标定自动叠加。

① 上传 ② 映射 ③ 预览 ④ 导入

① 上传解析

▶

支持按图层分管径的管网图（图层名含管径数字最佳）；阀门块 WID_Val-*、文字标注（设备编号等）自动识别。

📍 比例校准（多点）

▶

DXF 图层与卫星图有比例/角度偏差时用对应点校准：每组先点 DXF 图上的点（自动吸附最近的管点/阀门），再点 卫星图上的同一位置。三种拟合方案：多点橡皮筋 TPS（推荐，4~300 点） — 卫星图有局部畸变时唯一能精准贴合的方案，每个控制点精确落位、点间平滑变形（GIS 配准标准算法）；三点最小二乘 — 只有整体比例/角度偏差时够用；两点精确 + 验证 — 快速定解。TPS 要点撒满整个园区（范围外的区域会外推发飘），路牙、建筑角等清晰地物优先。

#DXF 点（局部坐标）卫星点（经纬度）残差

② 图层 / 阀门块 / 标注映射

▶

管道图层 → 管径 / 类型
导入图层段数总长(m)管径(mm)类型
阀门块 → 阀门类型
导入块名数量属性样本类型
文字标注层（用于阀门命名）

③④ 预览确认并导入

▶

预览无误后导入：管道按连通性分解为简单路径（交叉点断开），每条路径一条水管；阀门吸附到 1.5m 内最近管段并继承管径；所选标注层 2.5m 内最近的文字写入阀门名。重复导入同一图纸会产生重复数据。
