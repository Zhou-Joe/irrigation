# 账户邮件与发送配置界面

用户管理 → 用户列表 → 账户邮件，可为注册邮箱确认、密码重置分别选择保存过的 SMTP / Microsoft 365 Workflow 配置。两个功能默认不启用，管理员或经理选择并保存后启用。配置受账户邮件外键保护，不能在引用时直接删除。

启用注册确认后，新申请填写邮箱，点击邮件链接后还需在确认页提交确认，避免邮件扫描器仅访问链接便完成确认。确认链接 24 小时有效。确认后仍走原管理员审批；未确认的新申请不能批准。旧申请的审批要求不变。审批时将登记邮箱保存到 User.email。提供用户名+邮箱重发入口。

登录页增加忘记密码入口。密码重置仅面向有效且有可用密码的账号登记邮箱；请求响应不披露账号是否存在。采用 Django PasswordResetTokenGenerator 和 PasswordResetConfirmView，链接 1 小时有效，修改密码后失效，已有会话按 Django 密码哈希规则失效。未登记邮箱的旧账号需先登记或联系管理员。

账户邮件通过受限后台发送线程执行，发信频率有邮件地址与来源限流。发送失败记录不包含邮件链接或凭据，用户可稍后重发。系统不把密码写入邮件，也不在响应里返回重置令牌。

发送配置弹窗改为有固定头尾、可滚动内容的紧凑样式，使用方式卡片和响应式字段排列。移除用户填写下载站点：系统从公开访问域名确定并保存站点供定时任务使用；部署可通过 EMAIL_REPORT_PUBLIC_BASE_URL 覆盖。旧的配置级下载站点不再决定实际下载链接。

按用户要求，不进行浏览器验收、额外测试或实际试发。账户邮件功能待管理员选定配置后由用户验收。
